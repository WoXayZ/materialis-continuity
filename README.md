# Materialis Continuity

Unofficial **Forge 1.20.1** port of [Materialis](https://www.curseforge.com/minecraft/mc-mods/materialis) by RCXcrafter.

| | |
|---|---|
| **Mod ID** | `materialis` |
| **Version** | 1.20.1-1.1 |
| **Minecraft** | 1.20.1 |
| **Forge** | 47.4.28 |
| **Java** | 17 |

Materialis Continuity is an addon for [Tinkers' Construct](https://www.curseforge.com/minecraft/mc-mods/tinkers-construct). It adds extra tool materials, fluids, the wrench and battlewrench, and compatibility with other mods.

The in-game namespace stays `materialis` so existing datapacks and world data keep working.

## CurseForge

Page copy (summary, full description, relations, release changelog) is in [`CURSEFORGE.md`](CURSEFORGE.md).

## Build

```bash
./gradlew build
```

JAR: `build/libs/materialis-continuity-1.20.1-1.1.jar`
